# Web Technologies Practice

A hands-on collection of HTML and CSS exercises created while practicing core web development concepts. Each lesson is a small, standalone webpage that can be opened directly in a browser or served with VS Code Live Server.

## What this project covers

### HTML fundamentals

The [`HTML/`](HTML/) folder contains examples of:

- HTML document structure and HTML5 boilerplate
- Headings, paragraphs, block-level elements, and inline elements
- Attributes such as `id`, `class`, `style`, and `title`
- Text-formatting tags including `strong`, `em`, `mark`, `sub`, `sup`, `del`, and `ins`
- Links, email links, telephone links, page anchors, downloadable links, and linked images
- Images using relative and absolute URLs
- Ordered, unordered, nested, and description lists
- Tables with `rowspan` and `colspan`
- Forms with labels, text and email inputs, password fields, dates, numbers, radio buttons, checkboxes, selects, and validation attributes
- Audio, video, and iframe embeds

### CSS fundamentals and layouts

The [`CSS/`](CSS/) folder contains examples of:

- Inline, internal, and external CSS
- Simple, grouping, universal, combinator, pseudo-class, and pseudo-element selectors
- The CSS box model: content, padding, borders, and margins
- Text and font formatting, shadows, spacing, and alignment
- Background images, gradients, overlays, and multiple backgrounds
- Element positioning with relative and absolute positioning
- Flexbox wrapping and alignment
- CSS Grid page structure with a header, sidebar, content area, and footer
- Card layouts, hover states, icons, transitions, and profile-style components


## Suggested practice path

1. Start with the HTML document structure and basic elements.
2. Continue with attributes, headings, formatting, links, images, lists, and tables.
3. Practice forms and media embeds.
4. Move to CSS types, selectors, text formatting, and the box model.
5. Finish with positioning, Flexbox, Grid, backgrounds, and card layouts.
6. Modify each example to create your own content, colors, spacing, and responsive layouts.

## Learning goals

- Build pages with semantic HTML structure.
- Understand how HTML elements and attributes affect browser behavior.
- Connect external stylesheets to HTML documents.
- Use CSS selectors to target elements and states.
- Create layouts with Flexbox and Grid.
- Practice reusable visual components and hover interactions.
- Learn by experimenting with small, isolated examples.

## Project status

This is an educational practice repository rather than a production application. The examples are intentionally small and may contain alternative approaches, placeholder content, and experimental markup for learning purposes.
